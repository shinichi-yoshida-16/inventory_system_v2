## 1. はじめに
### 1.1 本書の目的
- 本書は、部品・消耗品の在庫を管理する「整備部品在庫管理システム」の操作方法をまとめた取扱説明書です。
- ログイン方法から、バーコード／QRコードを使った入出庫の登録、在庫確認、閾値・ユーザ情報の設定、トラブル時の対応まで、日常業務で必要となる操作を説明します。

### 1.2 このシステムでできること
- 部品・消耗品の在庫数を、紙を使わずリアルタイムに把握できます
- スマートフォンでバーコード・QRコードを読み取るだけで、入庫・出庫の記録ができます
- メーカー品のバーコード（JANコード／GS1 DataMatrix）を読み取れば、未登録の品目でもその場で新規登録できます
- 在庫数が設定した閾値以下になると、通知先として登録されているメールアドレスへ自動でメール通知が届きます
- いつでも在庫一覧画面で、現在の在庫数を確認できます

### 1.3 利用対象者
| 区分 | できること |
|---|---|
| 一般ユーザ | ログイン、自分のパスワード変更、在庫一覧の閲覧、コードスキャンによる入庫・出庫登録 |
| 管理者ユーザ | 一般ユーザにできること、QRコードの発行・印刷、閾値・廃番の設定、許可リストの閲覧・パスワードリセット、通知先メールアドレスの設定、時差更新の実行、在庫データの直接編集 |

> 注意 : 退職者は速やかに把握し、許可リストの退職フラグを設定してください（ユーザ行そのものの追加・削除はスプレッドシートの直接編集で行います）。

## 2. 利用環境
### 2.1 利用端末
| 端末 | 主な用途 |
|---|---|
| 個人所有のスマートフォン | ログイン、在庫確認、コードスキャンによる入庫・出庫、ユーザ情報（パスワード変更） |
| 貸与PC | QRコードの発行・印刷、閾値・廃番の設定、ユーザ情報（許可リスト・通知先設定）、在庫データの手動操作（管理者） |

### 2.2 アクセス先URL
- 本システムは単一のサイト（1つのアドレス）で構成されています。システム管理者から案内されたURLをブラウザで開き、ブックマークしておいてください。
- ログイン画面、ダッシュボード、在庫一覧、コードスキャン、QR発行、閾値設定、ユーザ情報のすべての画面は、同じサイト内のページとして遷移します（外部サイトへの移動はありません）。

### 2.3 スマートフォンでのカメラ利用について
- バーコード・QRコードの読み取りには、スマートフォンのカメラへのアクセス許可が必要です。
- 初めてコードスキャン画面を開いたとき、ブラウザから「カメラの使用を許可しますか」といった確認が表示された場合は「許可」を選択してください。許可しないとコードを読み取れません。
> 注意 : コードスキャン画面は、必ずSafari(iPhone)やChrome(Android)などの通常のWebブラウザで開いてください。LINEやInstagram等のアプリ内蔵のブラウザ(メッセージやリンクをアプリ内で直接開く機能)からアクセスすると、カメラが起動できません。その場合、画面に案内メッセージが表示されますので、案内に従って画面右上のメニューなどから「他のブラウザで開く」を選択してから操作してください。

## 3. ログイン方法(ログイン画面)
### 3.1 ログイン手順
1. ログイン画面を開きます。
2. 自分のメールアドレスとパスワードを入力します。
3. 「ログイン」ボタンを押します。
4. あらかじめ登録されている許可リストと照合され、一致すればダッシュボード画面に進みます。

### 3.2 ログインできない場合
- 入力したメールアドレス・パスワードの組み合わせが許可リストと一致しない場合はログインできません（メールアドレス未登録・パスワード誤り・退職フラグが設定されている、のいずれの場合も同じエラーメッセージが表示されます。理由の切り分けはできない仕様です）。
- パスワードを忘れた場合は、自分では再設定できません。管理者に依頼して、ユーザ情報画面からパスワードをリセットしてもらってください（[10章](#10-ユーザ情報パスワード変更許可リスト通知先設定)参照）。
- 上記で解決しない場合は、管理者へ許可リストへの登録・更新を依頼してください。
> 入力のご確認 : スマートフォンの日本語入力のまま(全角入力モード)でメールアドレスを入力すると、`＠`などの記号が全角文字になり、半角で登録されている許可リストと一致せずログインできないことがあります。英字入力モード(半角)に切り替えてから入力してください。

> セッションについて : ログイン状態（セッション）は30分間操作がないと自動的に無効になります。また、ブラウザの「更新（リロード）」ボタンで画面を再読み込みすると、30分以内でもログイン状態が失われ、ログイン画面に戻ります。画面を移動する際は、ブラウザの「戻る」「更新」ではなく、各画面内の「ダッシュボードに戻る」ボタンなどを使用してください。

## 4. ダッシュボード
- ログイン後に表示される画面です。以下の各画面への入口がまとまっています。表示されるボタンは、利用している端末（スマホ／PC）と自分の権限（一般／管理者）によって変わります。

| ボタン | 遷移先 | 利用できる端末 |
|---|---|---|
| 在庫一覧 | 在庫一覧画面（[5章](#5-在庫一覧の確認在庫一覧画面)） | スマホ／PC |
| コードスキャン | コードスキャン画面（[6章](#6-バーコードqrコードによる入庫出庫コードスキャン画面)） | スマホのみ |
| QRコード発行 | QR発行・印刷画面（[8章](#8-qrコードの発行印刷pcのみ管理者向け)） | PCのみ |
| 閾値設定 | 閾値・廃番設定画面（[9章](#9-閾値廃番の設定pcのみ管理者向け)） | PCのみ・管理者のみ |
| ユーザ情報 | ユーザ情報画面（[10章](#10-ユーザ情報パスワード変更許可リスト通知先設定)） | スマホ／PC |

- 画面共通のヘッダーには、ログイン中のメールアドレスと「ログアウト」ボタンが常に表示されます（[12章](#12-ログアウト)参照）。
> 注意 : 「コードスキャン」はスマートフォンの画面にのみ、「QRコード発行」「閾値設定」はPCの画面にのみ表示されます。「閾値設定」は管理者以外には表示されません。

## 5. 在庫一覧の確認（在庫一覧画面）
### 5.1 表示内容
- 在庫一覧画面では、廃番になっていないすべての品目について、以下の情報が一覧表示されます。
  - 品目ID
  - 品目名
  - 現在の在庫数
  - アラート閾値
  - 保管場所
- 現在の在庫数がアラート閾値以下になっている品目は、行の背景色と在庫数の表示が強調され、一目で分かるようになっています。
- スマートフォンなど画面幅が狭い場合は、表形式ではなく1品目ずつのカード形式で表示されます。

### 5.2 廃番品目の扱い
- 入手できなくなった部品は、管理者が「廃番」として設定できます（[9章](#9-閾値廃番の設定pcのみ管理者向け)）。
- 廃番に設定された品目は、在庫一覧画面から**表示されなくなります**（グレーアウト等での表示ではなく完全に非表示になります）。廃番の解除も管理者が行うことができ、解除すると再び一覧に表示されます。

### 5.3 時差更新ボタンについて（管理者のみ）
- 管理者でログインした場合、在庫一覧画面の下部に「時差更新」の機能が表示されます。詳しくは[11章](#11-時差更新について管理者向け)を参照してください。

### 5.4 データの直接編集について（管理者のみ）
- 管理者級の整備士は、Googleスプレッドシート（DB）を直接編集する権限を持ちます。ただし、以下の点に注意してください。

> 管理者の方へ : 他の整備士がコードスキャンで入出庫操作を行っている時間帯は、スプレッドシートの直接編集を行わないでください。システム側の排他制御（同時書き込みの競合防止）の対象外となるため、データがずれる可能性があります。万一ずれが発生した場合は、実際の在庫数を数えて棚卸を行い、システム上のデータを実数に合わせてください。

## 6. バーコード・QRコードによる入庫・出庫（コードスキャン画面）
- 日々の入庫・出庫は、この画面から行います。スマートフォンのみで利用できる機能です。
- 読み取れるコードは3種類です。品目に応じてどれを読み取っても、同じ画面で処理されます。
  - 自社で発行したQRコード（[8章](#8-qrコードの発行印刷pcのみ管理者向け)で発行したもの）
  - メーカー品のJANコード（バーコード）
  - メーカー品のGS1 DataMatrix（二次元コード）

### 6.1 登録済み品目の入庫・出庫手順
1. ダッシュボードの「コードスキャン」を押します。
2. カメラが起動するので、対象の部品・棚に貼られたバーコード・QRコードを画面に映します。
3. 読み取りが成功すると、品目名・現在の在庫数など対象品目の情報が表示されます。
4. 「入庫」または「出庫」を選び、数量を入力します。
5. 「登録」ボタンを押すと処理が完了し、完了メッセージが表示されます。
6. 「スキャンに戻る」を押すと、続けて別の品目を読み取れます。

### 6.2 未登録品目の自動登録（メーカー品バーコードの場合）
- メーカー品のJANコード・GS1 DataMatrixを読み取った際、まだシステムに登録されていない品目の場合は、新規登録の入力画面が表示されます。
1. 品目名・アラート閾値・保管場所を入力します。
2. 「登録して入庫」を押すと、品目が新規登録されると同時に1個入庫した状態で記録されます（品目IDは自動採番されます）。
- 自社発行のQRコード（ラベルが破損している等で本来登録済みのはずのもの）が未登録と判定された場合は、ラベルの誤りが疑われます。管理者に確認してください。

### 6.3 入庫・出庫時に自動的に行われること
- 在庫数が入力した数量分だけ増減します。
- いつ・誰が・どの品目を・何個・入庫／出庫したかが履歴として自動保存されます。
- 出庫の際、入力した数量が現在の在庫数を超える場合はエラーとなり、在庫数は更新されません。実際の在庫数を確認したうえで、正しい数量を入力し直してください。
- 出庫の結果、在庫数が閾値以下になった場合は、通知先に登録されているメールアドレス宛に自動でアラートメールが送信されます（[7章](#7-在庫アラートメールについて)参照）。
- 入庫により在庫数が閾値以上まで回復した場合、次に再び閾値を下回った際に、あらためてアラートメールが送信されるよう設定が更新されます。

### 6.4 コードスキャン画面で困ったとき

| 症状 | 対処方法 |
|---|---|
| カメラが起動しない／映像が真っ暗 | まず、LINEやInstagram等のアプリ内蔵ブラウザで開いていないか確認してください。その場合は案内メッセージに従ってSafari/Chrome等の通常のブラウザで開き直してください(2.3参照)。通常のブラウザで開いても起動しない場合は、スマートフォンのブラウザ設定でカメラの使用が許可されているか確認してください。 |
| 「読み取れないコードです」「バーコードのチェックディジットが一致しません」等のエラーが出る | コードの汚れ・破損、または対応していない形式のコードの可能性があります。もう一度「スキャンに戻る」から読み取り直してください。改善しない場合は管理者に相談してください。 |
| 出庫時に在庫不足のエラーが出る | 入力した出庫数が現在の在庫数を超えています。実際の在庫を確認し、正しい数量を入力してください。 |
| 登録ボタンを押しても反応がない／エラーになる | 通信状況をご確認のうえ、もう一度お試しください。「時差更新として受け付けました」と表示された場合は正常です（[11章](#11-時差更新について管理者向け)参照）。それ以外のエラーが続く場合は下記6.5の代替手段をご利用ください。 |
| セッション無効の画面に切り替わる | ログイン（セッション）が期限切れになっています。ログイン画面から再度ログインし、ダッシュボード経由でコードスキャン画面を開き直してください。 |

### 6.5 システムが使えないときの代替運用

> 緊急時の運用 : システム全体が一時的に利用できない場合は、無理に操作を続けず、紙に「日時・品目・入庫／出庫・数量・担当者」を記録してください。復旧後、まとめてシステムへ入力（またはコード再読取）することで在庫数を実態に合わせます。なお、一時的な混雑によるエラーは[11章](#11-時差更新について管理者向け)の時差更新でシステムが自動的に吸収するため、紙記録が必要になるのはシステム自体に接続できない場合に限られます。

## 7. 在庫アラートメールについて
- 在庫数が品目ごとに設定された閾値以下になった時点で、通知先として登録されているすべてのメールアドレス宛に、件名「在庫数アラート」の自動メールが送信されます。
  - 同じ品目について、閾値を下回ったことによる通知は、補充（入庫による回復）が確認されるまで再送されません。
  - 通知先メールアドレスの追加・変更は、管理者がユーザ情報画面（[10章](#10-ユーザ情報パスワード変更許可リスト通知先設定)）から行います。
  - メールが届かない場合は、まず自分がその品目の通知先に登録されているか、管理者に確認してください。
> 送信上限について : メール送信には1日あたりの送信件数の上限があります（Gmail無料アカウントで1日500通程度、Google Workspaceで1日2,000通程度）。通常の利用規模（整備士10名程度）であれば問題になることはありませんが、上限に達した場合は通知が一時保留され、管理者が次回ログインした際にまとめて送信されます。

## 8. QRコードの発行・印刷（PCのみ／管理者向け）
### 8.1 新規品目の登録とQRコード発行
- メーカーのバーコードを持たない部品（自社在庫の消耗品等）を登録する場合に使用します。
1. ダッシュボードから「QRコード発行」画面を開きます（PCのみで利用可能）。
2. 品目名・アラート閾値・保管場所を入力します。
3. 「登録してQR発行」を押すと、品目が新規登録され（品目IDは自動採番）、その品目専用のQRコードが自動的に生成されます。
4. 「印刷」を押すと印刷レイアウトが表示されるので、ラベル用紙（91mm×55mm相当）または普通紙に印刷します。
5. 印刷したQRコードを、対象の棚または部品箱に貼り付けます。

### 8.2 QRコードの再発行
- QRコードのラベルが破れた、汚れて読み取れなくなった等の場合は、一覧から対象の品目を選択するだけで、同じ品目IDのQRコードを再度生成・印刷できます。品目ID・品目名は変わらないため、初回発行時と同じ内容のQRコードが出力されます。
- 選択肢の一覧には、廃番に設定されている品目は表示されません。

## 9. 閾値・廃番の設定（PCのみ／管理者向け）
- ダッシュボードから「閾値設定」画面を開きます（PC・管理者のみで利用可能）。品目ごとに以下の設定ができます。

### 9.1 アラート閾値の設定
- 「在庫数がいくつ以下になったらアラートメールを送るか」という閾値を、品目ごとの入力欄に入力し、「閾値を一括更新」ボタンで保存します。複数品目をまとめて更新できます。

### 9.2 廃番の設定・解除
- 各品目の行にある「廃番にする」ボタンを押すと、その品目が廃番として設定され、在庫一覧・QR再発行の選択肢から非表示になります。
- 廃番にした品目は「廃番解除」ボタンでいつでも元に戻せます。

## 10. ユーザ情報（パスワード変更・許可リスト・通知先設定）
- ダッシュボードから「ユーザ情報」画面を開きます。スマホ・PCどちらでも利用できます。

### 10.1 自分のパスワード変更（全ユーザ共通）
1. 「パスワード変更」欄に、新しいパスワードを2回（本人確認用に同じものを）入力します（8〜72文字）。
2. 「更新」ボタンを押すと、パスワードが変更されます。

### 10.2 許可リストの閲覧・通知先設定（管理者のみ）
- 管理者でログインすると、「許可リスト・通知先設定」欄が表示されます。登録されている利用者が1つの表にまとめて表示されます（許可ID・メールアドレス・管理者かどうか・退職フラグ・通知先チェックボックス）。パスワードのハッシュ値は表示されません（平文のパスワードはシステム上どこにも保存されていません）。
- 表内の「通知先」列のチェックボックスを操作することで、その利用者を在庫アラートメールの通知先として追加・解除できます。
- 許可リストに登録されていないメールアドレスを通知先として追加したい場合は、表の下の入力欄にメールアドレスを入力し「追加」ボタンを押します。
- 利用者の追加・削除、退職フラグの設定は、この画面では行えません。従来どおりスプレッドシートの直接編集で行ってください。

### 10.3 他の利用者のパスワードリセット（管理者のみ）
1. 「パスワードのリセット」欄で、対象の利用者をプルダウンから選択します。
2. 新しいパスワードを2回入力し（8〜72文字）、「リセット」ボタンを押します。
3. リセット完了後、システムからは本人へ自動通知されません。新しいパスワードは口頭や社内の別の連絡手段で本人に伝えてください。

## 11. 時差更新について（管理者向け）
- 通信の混雑などにより、入庫・出庫の処理が一時的に完了できなかった場合、システムは自動的にその操作を保留（時差更新の対象）として受け付けます。この場合、操作した利用者には「時差更新として受け付けました」という完了扱いのメッセージが表示され、その場でエラーになることはありません。
- 保留された操作がある場合、在庫一覧画面の下部に管理者向けの「時差更新」ボタンが表示されます。
1. 在庫一覧画面を開きます（管理者でログイン）。
2. 「時差更新を実行」ボタンを押すと、保留されていた入庫・出庫が発生順にまとめて反映されます。
3. すべて反映できた場合は完了メッセージが、一部反映できなかった場合はその旨と件数が表示されます。反映できなかった分は保留されたままなので、時間をおいて再度実行してください。
> 補足 : 新規品目登録・閾値設定・廃番設定はこの時差更新の対象外です。これらの操作が失敗した場合はその場でエラーが表示されるので、再度操作をやり直してください。

## 12. ログアウト
- 各画面共通のヘッダーにある「ログアウト」ボタンを押すと、ログイン画面に戻ります。共有のPCやスマートフォンで利用した場合は、作業終了後に必ずログアウトしてください。

## 13. トラブルシューティング（よくある質問）

| 症状・質問 | 対処方法 |
|---|---|
| ログインできない | メールアドレス・パスワードの入力ミスがないか確認してください。パスワードを忘れた場合は管理者にリセットを依頼してください（3.2、10.3参照）。 |
| 急にログイン画面に戻された | 30分間操作がなかったか、ブラウザを更新（リロード）したためセッションが無効になった可能性があります。再度ログインしてください（3.2参照）。 |
| 在庫数が実際の数と合わない | 入出庫の記録漏れ、時差更新の未実施、または管理者による直接編集との競合が考えられます。実際の数を数えて棚卸を行い、管理者にデータの修正を依頼してください。 |
| 出庫しようとするとエラーになる | 入力した数量が現在の在庫数を超えています。実際の在庫数を確認し、正しい数量で登録し直してください（6.3参照）。 |
| コードが読み取れない | ラベルの汚れ・破損、または照明不足が考えられます。QRコードが不鮮明な場合は、8.2の手順で再発行してください。メーカーのバーコードが読み取れない場合は品目名等を確認のうえ管理者に相談してください。 |
| アラートメールが届かない | 自分がユーザ情報画面の通知先設定に登録されているか、迷惑メールフォルダに振り分けられていないかを確認してください（[10.2](#102-許可リストの閲覧通知先設定管理者のみ)参照）。 |
| 「時差更新として受け付けました」と表示された | 異常ではありません。一時的な混雑によるものです。管理者が在庫一覧画面から時差更新を実行すると反映されます（[11章](#11-時差更新について管理者向け)参照）。 |

## 14. 運用上の注意事項
- ご自身のメールアドレス・パスワードでログインしてください。パスワードは他人に教えないでください。
- コードスキャン画面は、必ずSafari/Chrome等の通常のWebブラウザで開いてください。LINE等のアプリ内ブラウザではカメラが使用できません(2.3参照)。
- 画面遷移にはブラウザの「更新」「戻る」ではなく、画面内のボタンを使用してください。ブラウザの更新を行うとログイン状態が失われます(3.2参照)。
- 他の整備士が入出庫操作を行っている時間帯は、管理者もスプレッドシートの直接編集を控えてください。
- 退職・異動が決まった際は、速やかに管理者へ連絡し、許可リストの退職フラグ設定を依頼してください。
- 定期的に実物の棚卸を行い、システム上の在庫数と実数のズレがないか確認してください。
- システム全体が長期間利用できない場合は、紙記録による代替運用に切り替えてください（6.5参照）。
